# Last Bell

Last Bell is a short, mobile-first onchain game concept for Robinhood Chain.
Players choose a ticker faction, pay the displayed action price to take the
bell, and try to hold it when the countdown reaches zero.

> Pick a bag. Pay $1 to steal the bell. Hold it at zero to win 50%.

The first implementation stage is a Next.js Channel 4663 static shell and
deterministic simulator. The first public MVP is planned for Robinhood Chain
testnet points. Player-funded prizes and Stock Token custody remain later gated
stages.
